# Citation

The atlas manuscript is in preparation. Until the manuscript and archived release are available, the atlas should be cited as a working resource from the Temple University collaboration that produced it, with version and date, together with a link to this site. The final release will carry a manuscript citation, a Zenodo digital object identifier, the repository URL and a version number.

## Suggested citation for this tutorial

Temple University. (2026). *MesoConnect Atlas tutorial* (Version 0.1) [Website]. https://diffusiontensorimaging-repos.github.io/MesoConnect-Tutorial/

## Related work

A morphometric study of the substantia nigra, ventral tegmental area and dorsal raphe using T1-weighted and diffusion imaging (Toppa et al., 2026) addresses the same midbrain structures from a volumetric perspective. Software and source atlases used in the workflow are cited on the pages where they are used and listed on the [references page](references).
