# Citation

The atlas is described in the manuscript *Mapping Mesolimbic Dopamine Projections to Subcortical Circuits Underlying Adaptive Behavior: A Human 7T Diffusion Tractography Atlas* (Elliott, Mopuru, Hoffman, Leong, Volkow, Olson, & Murty), currently under review. Work that uses the atlas or this workflow should cite that paper; the full reference and DOI will be added here when it is published. The atlas package's terms are scoped by material (Human Connectome Project (HCP)-derived maps under the WU-Minn HCP Consortium Open Access Data Use Terms; documentation and figures under CC BY 4.0; code under the MIT License; the Montreal Neurological Institute MNI152 template under the FSL licence); see the `LICENSE` file in the package and the [atlas repository](https://github.com/blelliott23/MesoConnect).

Source atlases and software used in the workflow are cited on the pages where they are used and listed on the [references page](references).
