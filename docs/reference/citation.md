# Citation

The atlas manuscript is in preparation. Until the manuscript and archived release are available, the atlas should be cited as a working resource from the Temple University collaboration that produced it, with version and date, together with a link to this site. The final release will carry a manuscript citation, a Zenodo DOI, the repository URL and a version number.

Software and source atlases used in the workflow are listed on the [references page](references).
