# Troubleshooting

| Symptom | Likely cause | What to do |
|---|---|---|
| Warped atlas shifted anterior or posterior | Poor T1 → MNI registration, or mismatched coverage (skull-stripped subject, full-head template). | Check the brain extraction; use the brain template; overlay the warped template on the T1 before warping labels. |
| Left and right appear swapped | Wrong transform, header orientation, mislabelled hemisphere. | `fslorient`, `fslhd`; overlay known asymmetric anatomy. |
| Atlas mask vanishes after warping | Threshold too strict after linear interpolation, or grid mismatch. | Inspect the probability map before thresholding; use 25%; warp the binary with nearest-neighbour. |
| Mask includes ventricle or gray matter | Registration error or too much dilation. | Smaller dilation; check in native space. |
| VTA lands in the peduncle or pons | Registration failed locally. | Re-run registration for that subject; consider a midbrain-weighted mask in `-x`. |
| `tckgen` reaches far fewer streamlines than target | Cutoff too high for the field strength; corridor too narrow; seed or target not connected to the corridor. | Run the pilot sweep; check the seed and target are inside the inclusion zone; try 25% atlas or one more voxel of dilation. |
| Tract looks thick or messy at a permissive cutoff | Expected before cleaning. | Compare cleaned bundles; if still messy, tighten the dilation. |
| Cleaning empties a subject | Two bundles being cleaned as one, or a very sparse raw tract. | QuickBundles split; check raw streamline count. |
| Profile endpoints reversed in some subjects | Orientation failed. | Force node 0 by the seed ROI; check the centroid orientation per subject. |
| Whole-tract NDI implausibly high or low | Grid mismatch, partial volume, global tissue differences. | Confirm the same grid; add a whole-white-matter NDI covariate; look at the overlay. |
| AMICO `FileNotFoundError` in parallel runs | Kernel directory regenerated by every job. | Generate kernels once on one subject first, then launch the pool. |
| `pip install pyAFQ` fails on `zipp` | Old system package. | `pip install --user --upgrade zipp`. |
| Coverage audit flags every corridor as too small | The corridor is under 1% of brain volume by design. | Raise the threshold or ignore that flag. |

## QA checklist

- Record atlas version, threshold, dilation, interpolation, transforms, cutoff, scalar maps, covariates, software versions.
- Inspect the atlas in MNI before warping.
- Inspect every warped ROI over the T1 and the diffusion image.
- Check voxel counts and volumes after warping.
- Save at least one overlay image per subject and step.
- Inspect streamlines in native space; compare to the atlas in MNI.
- Verify node ordering and node coverage.
- Check missingness by tract and subject before group models.
