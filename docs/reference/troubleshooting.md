# Troubleshooting

| Symptom | Likely cause | Action |
|---|---|---|
| Warped atlas displaced anterior or posterior | Poor T1 → MNI registration, or mismatched coverage (skull-stripped subject with full-head template). | Check brain extraction; use the brain template; overlay the warped template on the T1 before warping labels. |
| Left and right appear swapped | Wrong transform, header orientation problem, mislabelled hemisphere. | Check with `fslorient` and `fslhd`; overlay known asymmetric anatomy. |
| Atlas mask empty after warping | Threshold too strict after linear interpolation, or grid mismatch. | Inspect the probability map before thresholding; use 25%; warp the binary map with nearest-neighbour. |
| Mask includes ventricle or gray matter | Registration error or excessive dilation. | Reduce dilation; inspect in native space. |
| VTA in the cerebral peduncle or pons | Local registration failure. | Rerun registration for that subject; consider a midbrain-weighted mask via `-x`. |
| `tckgen` reaches far fewer streamlines than the target | Cutoff too high for the field strength; corridor too narrow; seed or target disconnected from the corridor. | Run the pilot sweep; confirm the seed and target lie inside the inclusion zone; try the 25% atlas or one more voxel of dilation. |
| Tract appears thick at a permissive cutoff | Expected before cleaning. | Compare cleaned bundles; if still thick, reduce dilation. |
| Cleaning removes nearly all streamlines | Two bundles cleaned as one, or a sparse raw tract. | QuickBundles split; check the raw streamline count. |
| Profile endpoints reversed in some subjects | Orientation failed. | Assign node 0 by the seed ROI; check the centroid orientation per subject. |
| Whole-tract NDI implausibly high or low | Grid mismatch, partial volume, global tissue differences. | Confirm the same grid; add a whole-white-matter NDI covariate; inspect the overlay. |
| AMICO `FileNotFoundError` during parallel runs | Kernel directory regenerated by every job. | Generate kernels once on one subject, then start the pool. |
| `pip install pyAFQ` fails on `zipp` | Outdated system package. | `pip install --user --upgrade zipp`. |
| Coverage audit flags every corridor as too small | Corridors are below 1% of brain volume by design. | Raise the threshold or disregard that flag. |

## QA checklist

- Record atlas version, threshold, dilation, interpolation, transforms, cutoff, scalar maps, covariates and software versions.
- Inspect the atlas in MNI space before warping.
- Inspect every warped ROI over the T1 and the diffusion image.
- Check voxel counts and volumes after warping.
- Save at least one overlay image per subject and step.
- Inspect streamlines in native space and compare to the atlas in MNI space.
- Verify node ordering and coverage.
- Check missingness by tract and subject before group models.
