A browser viewer for along-tract statistical results. Load a results file, filter by any column, and click a row for the node profile, clusters and left–right comparison. Files are parsed locally.

Data format
One row per node. Six required columns, outcome, tract, metric, node, t, p; everything else optional. Column names from 09b_nodewise_permutation.R (Node, t_value, p_value) are accepted as they are.
ColumnRequiredMeaning
outcomeyeswhat was predicted
tractyestract label, any number of tracts
metricyesthe along-tract measure (FA, NDI, ODI, FWF, MD …)
nodeyes0-based node index, any node count
t, pyesthat node's statistic and uncorrected p
hemispherenoL / R; enables the left–right panel
N, covariatesnoshown per analysis
extent_thresholdnopermutation cluster-size threshold; clusters at least this long are marked FWE-significant
cluster_p, passednoyour FWE cluster p and verdict
any other columnbecomes a filter (family, condition, cohort, site …)

Results

FWE = cluster passes the permutation extent threshold. Direction: Positive higher metric, higher outcome · Negative higher metric, lower outcome. Bars in the profile: coloured = node p < .05, grey = not; green band = FWE cluster.
